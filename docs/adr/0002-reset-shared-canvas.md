# ADR 0002: Resetを空のsnapshotとして配信する

- ステータス: 採用
- 日付: 2026-08-14

## 背景

共有キャンバスを全利用者から初期化できるReset操作と、最後に初期化された時刻の
表示が必要になった。時刻はDurable ObjectのHibernationや再起動を越えて保持し、
接続中の全クライアントと再接続したクライアントで同じ状態を観測できる必要がある。

## 決定

クライアントは`{"type":"clear"}`を送信する。Durable Objectはストレージの
`deleteAll()`が成功した後、サーバー時刻を`meta:clearedAt`へ保存する。その後、
空のセルと`clearedAt`を含む`snapshot`を接続中の全クライアントへ配信する。

`meta:clearedAt`が存在しない場合は、グローバルキャンバスへの最初の接続時刻を
保存する。このため、すべての`snapshot`は数値の`clearedAt`を持ち、`null`には
ならない。機能導入前から存在するセルは、最初の時刻初期化では削除しない。

Reset専用のサーバーメッセージは追加しない。`snapshot`を完全な状態置換として
使用することで、接続時とReset時に同じクライアント処理を利用し、従来のクライアントも
空の`snapshot`によってキャンバスを初期化できるようにする。

## 結果

- `clearedAt`はDurable Objectストレージに永続化される。
- 状態の削除と時刻の保存が完了するまで、クライアントへ初期化完了を通知しない。
- `deleteAll()`は、このDurable Objectが所有するセルとメタデータをすべて削除する。
  将来、同じObjectへ別機能の状態やalarmを追加する場合はResetの削除範囲を再検討する。
- `deleteAll()`と後続の`put()`の間にObjectが異常終了した場合でも、次回の
  コンストラクタ実行時に欠けた`clearedAt`を新しい時刻で補完する。
